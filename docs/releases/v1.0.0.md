# tunefetch 1.0.0

First public release. · Primera versión pública.

[English](#english) · [Español](#español)

## English

tunefetch is a command-line program that searches music on YouTube and SoundCloud, orders the results from best to
worst audio quality, and downloads the one you choose as mp3 (or m4a, flac, opus, wav) with cover art and tags.

### What it does

- **Search by name** (`artist - title`) **or download a link** to a track, album or playlist.
- **Identifies the song** on MusicBrainz to get the exact artist, title and duration. A remix, a different song, a
  30-second preview or a version with a very different duration never ranks above the real track.
- **A menu to choose** the result, with its audio quality, duration and match. `--auto` skips the menu.
- **Albums and playlists** are saved in a folder named after them, with numbered tracks. A single song is just a file.
- **mp3 by default** (about 245 kbps), `-f m4a` for iPhone. Files get the cover art, artist and title.
- **A progress bar**, and English and Spanish messages (it follows your system language).
- **Settings:** `config output` sets the download folder and `config language` the language.

### How to use it on Windows

1. Download `tunefetch.exe` below and put it in any folder.
2. Install ffmpeg if you do not have it: `winget install Gyan.FFmpeg`, then open a new terminal.
3. Open PowerShell in that folder and run:

```powershell
.\tunefetch.exe get "artist - title"
```

The music is saved next to `tunefetch.exe`. `.\tunefetch.exe --help` shows every command and option with examples.

### Good to know

- **Windows SmartScreen** may warn the first time because the file is not signed. Choose More info, then Run anyway.
  To check that the file is the one published here, compare `Get-FileHash .\tunefetch.exe` with `SHA256SUMS.txt`.
- **Audio quality:** YouTube and SoundCloud give lossy audio of about 130 kbps. Converting to mp3 or flac cannot add
  quality that the source does not have.
- **Bandcamp links fail** for now: Bandcamp blocks yt-dlp. Albums and playlists were tested with YouTube and
  SoundCloud.
- **Only a Windows build** is published. On Linux or macOS, install with
  `uv tool install git+https://github.com/enriender011/tunefetch`.

## Español

tunefetch es un programa de línea de comandos que busca música en YouTube y SoundCloud, ordena los resultados de
mejor a peor calidad de audio y descarga el que elijas como mp3 (o m4a, flac, opus, wav) con carátula y etiquetas.

### Qué hace

- **Busca por nombre** (`artista - título`) **o descarga un enlace** a una pista, álbum o lista.
- **Identifica la canción** en MusicBrainz para saber su artista, título y duración exactos. Un remix, otra canción,
  una vista previa de 30 segundos o una versión con una duración muy distinta nunca quedan por encima de la real.
- **Un menú para elegir** el resultado, con su calidad de audio, duración y coincidencia. `--auto` se salta el menú.
- **Álbumes y listas** se guardan en una carpeta con su nombre y las pistas numeradas. Una sola canción es un archivo.
- **mp3 por defecto** (unos 245 kbps), y `-f m4a` para iPhone. Los archivos llevan carátula, artista y título.
- **Barra de progreso**, y mensajes en español e inglés (sigue el idioma de tu sistema).
- **Ajustes:** `config output` cambia la carpeta de descargas y `config language` el idioma.

### Cómo usarlo en Windows

1. Descarga `tunefetch.exe` aquí abajo y ponlo en cualquier carpeta.
2. Instala ffmpeg si no lo tienes: `winget install Gyan.FFmpeg`, y abre un terminal nuevo.
3. Abre PowerShell en esa carpeta y ejecuta:

```powershell
.\tunefetch.exe get "artista - título"
```

La música se guarda junto a `tunefetch.exe`. `.\tunefetch.exe --help` muestra todos los comandos y opciones con
ejemplos.
